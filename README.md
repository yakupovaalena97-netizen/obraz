# Obraz

Цифровой путеводитель по художественным выставкам. Дипломный проект Алёны Якуповой, РАНХиГС 2026.

- `/` — путеводитель: игра из пяти ходов, путь и выставки Москвы
- `/igra/` — игра с выставками, которые можно оплатить Пушкинской картой
- `/v1/` — первая версия прототипа

Сайт статический, ничего не хранит и не собирает: всё считается в браузере.
